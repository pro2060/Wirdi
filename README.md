# وِرْدي

تطبيق أندرويد (Kotlin) لورد القرآن اليومي: جلستان (صباح/مساء)، كل جلسة صفحتان، تذكير كل ١٥ دقيقة لكل جلسة على حدة
حتى الضغط على «تم». أوقات الجلستين تحددها من داخل التطبيق.

## بناء الـ APK بدون Android Studio (GitHub Actions)
1. أنشئ مستودع جديد على GitHub (يفضل Private) وارفع كل ملفات المشروع (بما فيها مجلد `.github`).
2. تأكد إن مفيش أي كلمات سر أو API keys جوه المستودع (المشروع ده مفيهوش أصلًا).
3. من تبويب Actions شغّل «Build APK» (أو هيشتغل تلقائيًا مع أول push).
4. بعد ما يخلص ادخل على التشغيلة ونزّل الـ artifact باسم `wirdi-apk`، فك الضغط وثبّت `app-debug.apk` على الموبايل.

## بناء بـ Android Studio
افتح المجلد ← Build ← Build APK(s).
